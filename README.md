# HIRA Audit Viewer
### 심평원 EDI B02 청구파일 기반 산부인과 특화 사전심사 프로그램

[![Python](https://img.shields.io/badge/Python-3.9%2B-blue)](https://python.org)
[![Platform](https://img.shields.io/badge/Platform-macOS%20%7C%20Windows-lightgrey)]()

---

## 개요

심평원(건강보험심사평가원) EDI B02 형식의 진료비 청구파일을 파싱하여,
실제 삭감·조정이 자주 발생하는 항목을 청구 전에 자동으로 검출하는 사전심사 도구입니다.

산부인과 외래 청구 특성에 최적화되어 있으며,
임상 현장과 EMR QC 실무 경험을 바탕으로 실제 삭감 사례를 직접 로직으로 구현했습니다.

---

## 개발 배경

- 임상병리사 면허 보유
- 산부인과 의원·전문병원 2년 이상 임상 경험
- EMR 벤더 QC/CS 경력 (심평원 EDI 청구 실무)

청구 담당자가 수천 건의 명세서를 수동으로 확인하는 비효율을 줄이고,
삭감 위험 항목을 사전에 자동 검출하기 위해 개발했습니다.

---

## 주요 기능

### 파일 파싱
- 심평원 EDI B02 형식 청구파일 로드 및 파싱
- H·A·B·C·D·E 레코드 전체 지원
- CP949 인코딩 처리, 바이트 단위 정밀 파싱

### UI
- 수진자 목록 (이름·명세서번호·확인필요 표시)
- 명세서 일반내역(A) / 상병내역(B) / 진료내역(C) / 처방내역(D) / 특정내역(E) 탭별 조회
- 코드 검색 및 필터
- 전체 건수 / 조회 건수 실시간 표시

### 사전심사 조건 (9개)

|---|------|------|

| 2 | R4106 상병 누락 | B373 또는 N72 상병코드 필수 |

| 9 | **주수 불일치 검사** | JT005 기준 14주 미만인데 2·3삼분기 코드 청구 시 오류 |

### 조건 8 상세 — 임산부 초음파 통합 심사

고시 제2019-166호 기준으로 동일 주민번호를 가진 환자의 월간 명세서를 횡으로 묶어 분석합니다.

```
[1삼분기 일반]   EB511/512  →  2회까지 메모 불필요, 3회부터 JX999 필수
[1삼분기 정밀]   EB513/514  →  1회까지 메모 불필요, 2회부터 JX999 필수
[2,3삼분기 일반] EB515/516  →  1회까지 메모 불필요, 2회부터 JX999 필수
[2,3삼분기 정밀] EB517/518  →  1회까지 메모 불필요, 2회부터 JX999 필수
```

- 일반/정밀은 별개 카운팅 (합산하지 않음)
- JX999 메모는 특정 명세서가 아닌 **그룹 전체 총 개수**로 판정
- 날짜순 정렬 후 부족분만큼 해당 명세서에 에러 표시

## 설치 및 실행

### 소스 실행
```bash
# 의존성 없음 (Python 표준 라이브러리만 사용)
python3 review.py
```

### macOS 앱으로 빌드
```bash
pip3 install pyinstaller
pyinstaller --windowed --name "HIRA사전심사" review.py
# dist/ 폴더에 HIRA사전심사.app 생성
```

## 사용 방법

1. **EDI 청구파일(.B02) 불러오기** 버튼으로 파일 로드
2. 좌측 수진자 목록에서 환자 선택 → 우측에 레코드별 내역 표시
3. **사전심사 실행** 버튼 클릭
4. 하단 사전심사 결과 패널에서 삭감 위험 항목 확인
5. ❗ 표시된 환자 우선 검토 후 병원 EMR에서 수정
